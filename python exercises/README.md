# Python Practice Tasks

These exercises are designed to prepare you for the TODO tasks in `safe.py`.

Work through the files in this order:

1. `01_variables.py`
2. `02_terminal_io.py`
3. `03_control_structures.py`
4. `04_loops.py`
5. `05_functions.py`
6. `06_oop.py`

Each file contains explanations, small examples, and TODO sections.

## How to run an exercise

Open a terminal in this folder and run:

```bash
python 01_variables.py
```

On some Linux systems you may need:

```bash
python3 01_variables.py
```

## Recommended workflow

1. Read one TASK.
2. Write only the code for that TASK.
3. Run the file.
4. Check the output.
5. Continue with the next TASK.

Do not worry if something does not work immediately. Use `print()` to inspect variable values and compare your code with the Python cheat sheet.
